# SoftHome

Draggable on-screen Home button for **iPhone OS 1.0–1.1.5** (armv6).

Tap the circle to emulate the hardware Home button. Drag it anywhere. Position is saved.

## Usage

- **Tap** — Home (leave app / first SpringBoard page)
- **Drag** — move; position stored in `NSUserDefaults`
- Button re-attaches to the key window so it stays on top
